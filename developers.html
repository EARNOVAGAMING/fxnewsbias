FXNewsBias Developer API

The current news-sentiment read for 8 major currencies - the same scores that power the FXNewsBias dashboard, as clean JSON. Refreshed every 3 hours, around the clock.

Access

Sandbox keys are issued on request. If you already have a key, it works with the examples below.

Quickstart

curl -H "Authorization: Bearer fxnb_live_YOUR_KEY" \
  https://fxnewsbias.com/api/v1/sentiment

Response

{
  "schema": "fxnb.sentiment.v1",
  "generated_at": "2026-08-21T09:00:12Z",
  "next_update_expected": "2026-08-21T12:00:00Z",
  "attribution": {
    "required": true,
    "text": "Data by FXNewsBias",
    "url": "https://fxnewsbias.com"
  },
  "data": [
    { "currency": "USD", "score": 72, "bias": "Bullish",
      "updated_at": "2026-08-21T09:00:00Z" },
    ...
  ]
}
FieldContract (frozen, v1 never changes shape)
dataAlways exactly 8 rows, ordered USD, EUR, GBP, JPY, AUD, CAD, CHF, NZD
scoreInteger 0-100. 50 is the neutral midpoint; higher = bullish news tone, lower = bearish
biasExactly one of Bullish, Bearish, Neutral
updated_atISO-8601 UTC. When the score was computed (3-hour cycles)
next_update_expectedThe next scheduled refresh. Polling faster than 3-hourly just returns the same values

Rate limits

  • 100 requests per UTC calendar day per key, resetting at 00:00 UTC, comfortably enough for hourly polling with headroom
  • Every response carries X-RateLimit-Limit, X-RateLimit-Remaining and X-RateLimit-Reset
  • Request 101 returns 429 with a Retry-After header

Attribution & terms

  • Wherever the data is displayed or republished, retain the attribution: "Data by FXNewsBias" linking to https://fxnewsbias.com (it's included in every response)
  • Sandbox is for personal and internal non-commercial use
  • No redistribution, resale, or use to build a competing sentiment service
  • Keys can be revoked for abuse; request a new key any time (the old one is revoked automatically)
